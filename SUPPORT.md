# Support

NVIDIA Config Manager is maintained by NVIDIA for open-source collaboration.

## Getting Help

- Use GitHub issues for reproducible bugs, feature requests, documentation
  corrections, and general questions.
- Include the version or commit, deployment method, affected component, and
  relevant logs when opening an issue.
- Check the main [README](README.md), [documentation source](docs/README.md),
  and [installer guide](installer/README.md) before filing a new issue.

## Security Issues

Do not report security vulnerabilities through public GitHub issues. Follow the
private disclosure process in [SECURITY.md](SECURITY.md).

## Support Level

This repository is maintained as an open-source project. Public issue responses
are handled on a best-effort basis and do not replace any separate NVIDIA
enterprise support agreement.
