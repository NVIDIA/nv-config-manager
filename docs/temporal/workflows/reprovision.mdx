Completely reprovisions a network device with a new configuration, credentials, and operational parameters.

## User Interface

### Form Inputs

| Field | Description | Selection Type | Required |
| :---- | :---------- | :------------- | :------- |
| **Site** | Choose the site containing the device | Single dropdown from available sites | Yes |
| **Device** | Select the device to reprovision | Single dropdown from devices in selected site | Yes |

## Workflow Execution

### Execution Stages

1. Prepare device for reprovisioning
1. Deploy operating system
1. Apply device configuration
1. Validate reprovisioning
